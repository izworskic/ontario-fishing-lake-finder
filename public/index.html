Source model

A lake does not need a fish record to exist here.

All-lakes discovery uses the Ontario Hydro Network Waterbody polygon layer. Fisheries filters use Ontario Aquatic Resource Area evidence joined through Waterbody Location Identifier records when available.

  • Ontario reports more than 250,000 lakes; the tool does not equate the smaller fisheries-location layer with the physical lake inventory.
  • Missing fisheries evidence stays missing; it is not interpreted as “no fish.”
  • The browse list is bounded for usability. Map coverage is independently checked for the current viewport.
  • If the viewport contains too many lakes for safe interactive rendering, the tool gives the true count and asks you to zoom instead of silently sampling.
  • Distance-from-you is straight-line distance only, not drive time.
Decision boundaries

Lake Match and Trip Context remain narrow claims.

Lake Match appears only when fisheries evidence is being evaluated. Trip Context can add access, roads/barriers, active fire, Ontario 511 and Environment Canada evidence after selection.

Neither is a catch forecast, fish-population estimate, legal access determination, route-time estimate or safety clearance. Crown-land context is not legal access permission.
