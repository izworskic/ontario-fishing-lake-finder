What “remote” means here

Measured from mapped context, not vibes.

Remote Context uses distance to mapped Ontario Road Network features and source-published fishing access points. Crown-land and road-barrier records add planning context. No mapped access record is never treated as proof that a lake has no access.

  • Trout Fit uses ARA species, thermal, depth and stocking evidence.
  • Remote Context is scored separately and carries a confidence value.
  • No recent stocking record means exactly that; it does not prove a wild population.
